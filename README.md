# BeeSound

An e-commerce website for headphones and speakers, built from a Figma design using HTML, CSS and Bootstrap.

**Live Demo:** https://mo7-adad.github.io/beesound/

## Pages

- **Home** – hero banner, best selling products, offers, Black Friday discounts and new arrivals
- **Our Collection** – product grid
- **Product Details** – image gallery, product specs and related products

## Built With

- HTML5
- CSS3
- Bootstrap 5 (Navbar, Grid, Cards, Forms)
- Bootstrap Icons
